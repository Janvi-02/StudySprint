# 📚 StudySprint

StudySprint is a simple web-based productivity tool designed to help students organize their study sessions and stay consistent with their learning goals.

## 🚀 Features

* ⏱️ Study session timer
* 📋 Simple study-focused interface
* 🎯 Helps maintain focused study sessions
* 📱 Responsive design for different screen sizes
* ⚡ Lightweight and easy to use

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

## 💻 Getting Started

To run StudySprint locally:

1. Clone the repository:

```bash
git clone https://github.com/janviaggarwal/StudySprint.git
```

2. Navigate to the project directory:

```bash
cd StudySprint
```

3. Open `index.html` in your browser.

No additional dependencies or installation are required.

StudySprint was created as a small project to practice front-end web development and build something useful for students.
